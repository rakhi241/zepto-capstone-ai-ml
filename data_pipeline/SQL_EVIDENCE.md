# SQL Query Evidence

The executable SQL is stored in `data_pipeline.py` under `QUERIES`.

When the pipeline is run, the exact printed results are saved to:

- `outputs/sql_query_output.txt`
- `outputs/join_comparison.txt`
- `outputs/join_sql_vs_pandas.csv`

The seven queries collectively demonstrate the required SQL clauses: `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `DISTINCT`, `IN`, `BETWEEN`, and `JOIN`.
